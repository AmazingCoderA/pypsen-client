# Как отправить первый PR без `gh` и без локального клона

Способ через сайт GitHub — самый простой и не требует ничего ставить.

## Шаг 1. Сделай fork

1. Открой https://github.com/Ahmet-Dedeler/awesome-gta6-reverse-engineering
2. Нажми **Fork** → **Create fork**.
3. У тебя появится `https://github.com/<твой-логин>/awesome-gta6-reverse-engineering`.

## Шаг 2. Внеси одну строку

1. В своём форке открой `README.md` и нажми иконку карандаша (Edit).
2. Найди строку, начинающуюся с `| **Leonida**` (стойка с DMCA — она без бейджа звёзд).
3. Сразу после неё вставь **одну строку** из файла `pr-1-leonida-row.txt`.
   Вставь целиком, без переносов внутри строки. Это Markdown-таблица: строка должна начинаться и заканчиваться `|`.
4. Внизу страницы напиши commit message, например:
   `docs: add ProjectLeonidaL/leonida continuation`
5. Нажми **Commit changes**.

## Шаг 3. Открой PR

1. Нажми **Contribute** → **Open pull request**.
2. Заголовок и текст тела — из `outreach.md`, раздел 3.
3. Нажми **Create pull request**.

## Шаг 4. Второй PR

После того как первый PR принят (или хотя бы получил ответ), повтори всё для `Native-Victory-macOS`:
найди строку с `[Xenora]` в таблице macOS и вставь после неё строку из `pr-2-macos-row.txt`.
Заголовок и текст — из `outreach.md`, раздел 3.

## Если всё-таки захочешь консоль

`gh` ставится отдельно с https://cli.github.com, затем `gh auth login` открывает браузер для входа.
Это удобно для `gh pr create`, но **совсем не обязательно**: сайт делает то же самое.

## Как я проверял строки

Строки сверены с актуальным README через GitHub API 2026-11-26:
- `ProjectLeonidaL/leonida` и `LakshanSivakumar/Native-Victory-macOS` в списке отсутствуют;
- формат бейджа звёзд скопирован с соседней строки, чтобы PR прошёл проверку формата;
- описания статуса взяты из README самих проектов, без преувеличений.

## Частые причины отказа (чтобы не получить reject)

- Добавил два проекта в одном PR → правило CONTRIBUTING.md говорит «one item per PR». Делай два PR.
- Добавил мусорный репозиторий-клон без истории → список отклоняет пустышки и копии без оригинальной работы.
- Написал «playable» → nowhere near playable; пиши как есть.
- Приложил скриншот из игры → мгновенный отказ по asset policy.
