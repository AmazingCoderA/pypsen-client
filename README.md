# Pypsen v2

Клиентский Fabric-мод для **Minecraft 1.20.1**, **1.21.11** и **26.3**. Один исходный код, три отдельные сборки.

## Требования

| Minecraft | Fabric Loader | Fabric API | Java |
| --- | --- | --- | --- |
| 1.20.1 | 0.18.4 | `0.92.12+1.20.1` | 17+ |
| 1.21.11 | 0.18.4 | `0.141.6+1.21.11` | 21+ |
| 26.3 | 0.20.1 | `0.167.0+26.3` | 25+ |

## Сборка

Для сборки используется Gradle 9.8.0 + Fabric Loom 1.19.4, поэтому Gradle и Loom запускаются под JDK **25** для всех трёх целей. Байткод мода при этом отличается: `1.20.1` — Java 17, `1.21.11` — Java 21, `26.3` — Java 25.

```bash
./gradlew build -PmcTarget=1.20.1
./gradlew build -PmcTarget=1.21.11
./gradlew build -PmcTarget=26.3
```

На Windows:

```powershell
.\gradlew.bat build -PmcTarget=1.20.1
.\gradlew.bat build -PmcTarget=1.21.11
.\gradlew.bat build -PmcTarget=26.3
```

Готовые JAR-файлы появляются в `build/libs/`. Каждая цель имеет отдельное имя, поэтому сборки не перезаписывают друг друга.

## Установка

1. Установите Fabric Loader нужной версии Minecraft.
2. Положите Fabric API и подходящий JAR Pypsen в папку `mods`.
3. Запустите клиент.

## Управление

| Клавиша | Действие |
| --- | --- |
| `-` | Открыть меню мода |
| `V` | Speed |
| `R` | KillAura |
| `G` | Fly |
| `X` | XRay |
| `H` | Hitbox |

Остальные бинды назначаются прямо в GUI (кнопка `Key` → нажмите клавишу; middle click сбрасывает бинд). Средняя кнопка мыши по игроку добавляет/убирает его из списка друзей.

В меню есть классический и современный GUI, пресеты и кнопки сохранения конфига. Все экраны прокручиваются колесом мыши (в современном GUI — отдельно для каждой колонки; окна можно перетаскивать, они не выходят за экран). AI KillAura, Crystal Aura, FakeLag, AutoEat и Visual FX теперь доступны и в классическом меню; кнопка **Advanced Features** открывает отдельный экран из 8 страниц с полным набором настроек. Все прежние опции сохранены, добавлены новые режимы и переменные параметры.

## Конфиг

Файл `run/pypsen_config.txt` создаётся/обновляется кнопкой **Save Config** в меню. Там же хранятся друзья, выбранные блоки XRay и все новые настройки продвинутого экрана. AI KillAura дополнительно сохраняет обучающую выборку в `pypsen_ai.txt` (имя файла настраивается); можно вручную переобучить модель на `100`, `500` или `2000` выборок, включить автообучение и автосохранение. Старые файлы выборки из 6 колонок загружаются автоматически.

## Возможности

- **Combat:** KillAura (режимы/ротации/таргетинг, Shield Breaker, тайминг Fall/Jump для критов), отдельный режим `NOT NEAR` с настраиваемой дистанцией, независимые выключатели вращения и стрейфа, а также отдельный слот кастомного пресета — встроенные `Funtime`, `ReallyWorld`, `Test`, `HvH` при этом не изменяются. AI KillAura (пресеты `Balanced`/`Aggressive`/`Legit`/`HvH`/`Smart`, 5 режимов выбора цели, 4 режима ротации, логистическая модель с 8 признаками, позитивные/негативные примеры, автообучение и файл выборки `100-2000`), Crystal Aura (7 режимов: `Attack + Place`, `Attack Only`, `Smart Danger`, `AntiTotem Rush`, `FacePlace`, `Crystal Storm`, `Safe Hybrid`; 5 режимов цели, 4 позиции размещения, проверка урона себе, предсказание движения, лимит кристаллов, оффхенд), AutoClicker, TriggerBot (CPS, задержка, джиттер, фильтры целей, авто-оружие, scan FOV), AutoTotem, AutoEat (яблоки/еда по HP и голоду), AutoArmor, FastBow, AimAssist (6 методов: `Smooth`, `Linear`, `Snap`, `Spiral`, `Jitter`, `Silent`; дальность, FOV, скорость, приоритет цели и фильтры) / AimLock. Исправлены фильтры AntiBot для мобов и задержка атаки KillAura.
- **Movement:** Speed, Fly, Spider + Spider Pro (`Wall Climb`, `AntiStuck`, `Phase Jump`, `Turbo`), новые режимы Spider `Bypass Plus`/`Turbo Plus` и общий множитель скорости, NoWeb, Freeze с режимами `Smooth Lock`/`Silent Lock` и выключателем визуала, AirJump с режимом `Real Blocks` и множителем скорости, NoFall, Jesus, Noclip + Noclip Pro (`Phantom`, `Phase Step`, `Compact`, `Ghost`), Velocity, Strafe, Anti-Flag, FakeLag (`Motion`, `All C2S`, `Burst`).
- **Visuals:** XRay с сохранением списка блоков, четырьмя режимами (`Selected`, `Containers`, `Ores`, `Deep Scan`), тремя обходами рендера, режимом `Anti-XRay` и дальним сканером до 1024 блоков по уже загруженным чанкам; Base Finder ищет сундуки, шалкеры, дерево в пещерах, ковры и необычные блоки, подсвечивает чанки разными цветами, слабым свечением и четырьмя способами рендера (`Points`, `Boxes`, `Glow`, `Heatmap`). 2D ESP (боксы, имена, здоровье, дистанция, трассеры, предметы, фильтры мобов/животных), Glowing ESP, Target ESP (3D-рамка, метка с HP и частицы; работает отдельно от Glowing ESP), Target HUD с 5 стилями и радужным режимом, детализация тегов (FRIEND/ENEMY, щит, броня), FullBright, NameHider. Добавлены 6 стилей прицела, 6 цветовых тем, 4 стиля hitmarker, damage flash, target trail, combo counter, kill feed, skeleton ESP и scanlines. Кастомный **Ambient**: фон/туман (`Tint`, `Fog`, `Vignette`, `Gradient`, `Spiral`) с настраиваемой силой, оттенком и радужным режимом. Отдельные **Spins**: `Spin`, `Reverse`, `Pulse`, `Helix`, `Orbit` со скоростью и размером, кольца вокруг прицела и цели. Всё сохраняется в конфиге и отключается через Panic.
- **Misc:** Freecam, GodMode, Panic и прочие утилиты. Panic теперь отключает и все новые модули. Client-side stealth-профили скрывают локальный HUD, подменяют только клиентские подписи и добавляют случайные задержки/display-варианты без новых сетевых атак. **Server Crasher** теперь только локальный бенчмарк сложной математики: он не отправляет пакеты, не спамит и не может выкинуть игрока с сервера. Креативные дропы и лаборатория дупов работают локально и только в креативе; серверные эксплойты не добавлены.

## Релизы

При push тега вида `v*` GitHub Actions собирает **три версии** и прикрепляет все JAR-файлы к релизу. Артефакты каждой версии также доступны в artifacts соответствующего таска.

Сборки проверены компиляцией, метаданными и ремапом миксинов; поведение в игре не проверено.
